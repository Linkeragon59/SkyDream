Linux Dev:

- Installed VisualStudioCode, and Cmake Tools : https://code.visualstudio.com/docs/cpp/cmake-linux
- Build and install lastest CMake:
    - requires OpenSSL dev : sudo apt-get install libssl-dev
    - ./configure
    - make
    - sudo make install
- GLFW : require X11 dev installed
	- sudo apt install libx11-dev
	- sudo apt install libxcursor-dev
	- sudo apt install libxrandr-dev
	- sudo apt install libxinerama-dev
	- sudo apt install libxi-dev
- Touchscreen : magic-touchscreen
    - sudo apt install libevdev-dev
